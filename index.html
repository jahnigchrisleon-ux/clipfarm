Clpifarm

Clpifarm ist ein lokales Programm, das mit Erlaubnis des Streamers Highlights aus Livestreams erkennt, daraus Kurzvideos erstellt und diese als Entwurf in das eigene TikTok-Konto lädt. Veröffentlicht wird immer von der Nutzerin oder dem Nutzer selbst in der TikTok-App.

Clpifarm is a locally run tool that, with the streamer's permission, detects highlights in livestreams, creates short clips and sends them as a draft to the user's own TikTok account. Posting is always done by the user in the TikTok app.

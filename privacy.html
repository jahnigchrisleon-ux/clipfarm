2. Worum es geht

Clpifarm ist ein Programm, das auf dem eigenen Computer der Nutzerin oder des Nutzers läuft. Es nimmt mit Erlaubnis des Streamers einen Twitch-Livestream auf, erstellt Kurzvideos (Clips) und kann diese als Entwurf in das eigene TikTok-Konto hochladen. Wir betreiben dafür keinen zentralen Server und führen keine Nutzerkonten.

3. Welche Daten verarbeitet werden

Alle folgenden Daten werden ausschließlich lokal auf dem Computer der Nutzerin oder des Nutzers gespeichert und nicht an uns übermittelt:

  • TikTok-Zugangsdaten: Wenn Sie Ihr TikTok-Konto verbinden, erhält das Programm über den offiziellen TikTok-Login (Login Kit) ein Zugriffs- und ein Aktualisierungs-Token mit den Berechtigungen user.info.basic und video.upload. Sie werden nur verwendet, um von Ihnen freigegebene Videos als Entwurf in Ihre TikTok-Inbox zu laden.
  • Einstellungen und Clips: Konfiguration, erzeugte Videodateien, Untertitel und Beschreibungstexte liegen im Programmordner.
  • Twitch-Chat: Das Programm liest den öffentlichen Chat des gewählten Kanals anonym mit, um die Häufigkeit von Nachrichten zu zählen. Nachrichteninhalte und Nutzernamen werden nicht gespeichert.
  • Optionaler KI-Chat: Nur wenn Sie einen eigenen Anthropic-API-Schlüssel hinterlegen, werden Ihre Chat-Nachrichten sowie Programmstatus, Einstellungen, Log-Auszüge und Clip-Beschreibungen an die Anthropic-API gesendet. Es gelten die Datenschutzbestimmungen von Anthropic.

4. Weitergabe an Dritte

Daten werden nur an die Dienste übertragen, die Sie selbst nutzen: TikTok (Verbindung und Upload), Twitch (Aufnahme und Chat) und optional Anthropic (KI-Chat). Wir verkaufen keine Daten und nutzen keine Werbe- oder Tracking-Dienste.

5. Verbindung trennen und Löschung

Sie können das TikTok-Konto im Programm über „Abmelden“ trennen, wodurch das gespeicherte Token gelöscht wird. Zusätzlich können Sie den Zugriff in den TikTok-Einstellungen unter „Sicherheit und Berechtigungen“ widerrufen. Alle lokal gespeicherten Daten löschen Sie durch Löschen des Ordners data im Programmverzeichnis.

6. Diese Webseite

Diese Seite setzt keine Cookies und nutzt keine Analyse- oder Tracking-Werkzeuge. Der Hosting-Anbieter kann technisch bedingt Server-Logdaten (z. B. IP-Adresse, Zeitpunkt des Abrufs) verarbeiten.

2. What this is

Clpifarm is software that runs on the user's own computer. With the streamer's permission it records a Twitch livestream, creates short video clips and can upload them as a draft to the user's own TikTok account. We do not operate a central server and do not keep user accounts.

3. Data processed

All of the following is stored only locally on the user's computer and is not sent to us:

  • TikTok credentials: When you connect your TikTok account through the official TikTok Login Kit, the software receives an access token and a refresh token with the scopes user.info.basic and video.upload. They are used only to send videos you approved to your TikTok inbox as drafts.
  • Settings and clips: configuration, generated video files, subtitles and captions are stored in the program folder.
  • Twitch chat: the software reads the public chat of the selected channel anonymously to count message frequency. Message contents and usernames are not stored.
  • Optional AI chat: only if you provide your own Anthropic API key, your chat messages plus program status, settings, log excerpts and clip captions are sent to the Anthropic API, which is subject to Anthropic's privacy terms.

4. Sharing

Data is sent only to the services you use yourself: TikTok (connection and upload), Twitch (recording and chat) and optionally Anthropic (AI chat). We do not sell data and use no advertising or tracking services.

5. Disconnecting and deletion

You can disconnect your TikTok account in the software ("Abmelden"), which deletes the stored token. You can also revoke access in TikTok under "Security and permissions". To delete all locally stored data, delete the data folder in the program directory.

6. This website

This site sets no cookies and uses no analytics or tracking. The hosting provider may process technical server logs (for example IP address and time of access).
